Quick Setup and Commands — Agent Helper

Environment setup:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
python -m pip install -r dev-requirements.txt
```

Install Playwright browsers (needed for PDF generation/tests):

```bash
python -m playwright install chromium --with-deps --only-shell
```

Common dev commands:

- Lint & auto-fix: `python -m ruff check . --fix`
- Lint check: `python -m ruff check .`
- Run tests: `pytest -q`
- Run app (dev): `python app/run.py` (verifique `app/run.py` para hooks de inicialização)

Where to look:

- Modules: `app/modules/{sections,tabular,status}`
- Templates: `app/templates/` (Jinja2 files)
- Extensions: `app/extensions/` (templating, playwright pool, logging)

Testing notes:

- Tests mock framework parts; prefer `monkeypatch` for runtime patches.
- Ensure `PYTHONPATH` includes repository root or `app` depending on test setup.

Commit & PR guidance:

- Use branch naming `feature/*` or `fix/*`.
- Small commits; run tests before pushing.

If you need to run CI or manage PRs using the GitHub API, request a PAT with `repo` and `workflow` scopes.
